# Tic Tac Toe 

A simple tic tac toe game

## Lessons

The main lesson to learn from this project was function factories and closures. This project was an opportunity to learn about to organize your code going forward. A great article gave exposure to this concept : [building a house from inside out](https://www.ayweb.dev/blog/building-a-house-from-the-inside-out), which tells how to make use of factories and separate logic and dom.

## Built with
- Vanilla Js
- HTML5
- CSS3
